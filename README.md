# Extract tgWebAppData

**Me On Telegram** https://t.me/Imebrahim

### This script will help you to extract the `tgWebAppData` parameter from a URL.

**Extract tgWebAppData** is a simple tool designed to extract the `tgWebAppData` parameter from a URL. The repository includes a webpage tool that you can use to automate the process.

---

## Features

- Extracts the `tgWebAppData` parameter from a URL.
- Includes a webpage tool to simplify the process.
- Works with a browser for easy setup.

---

## How to Run?

Follow these steps to set up and use Extract tgWebAppData:

### 1. Open the Webpage

- Open the webpage tool at [http://querydecoderz.fwh.is/](http://querydecoderz.fwh.is/).

### 2. Enter the URL

- Enter the URL containing the `tgWebAppData` parameter in the input field.

### 3. Extract the Data

- Click the **Extract** button to extract the `tgWebAppData` parameter.

### 4. Copy the Data

- The extracted data will be displayed in a textarea. Click the **Copy** button to copy the data to your clipboard.
